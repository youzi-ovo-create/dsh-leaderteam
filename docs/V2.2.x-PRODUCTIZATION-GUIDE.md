# Leader Team V2.2.x 产品化功能使用指南

本指南说明 V2.2.x 开源线（Apache-2.0）新增的 **Magpie 生态网关集成**、**LT 原生前端与四套河洛序主题**、**DSH 双前端无缝切换** 及 **衡账（`lt-usage-plugin`）非阻塞成本统计**。

## 1. 启动与双前端无中断切换

### 在 DSH Web 宿主内使用（推荐，共享同一运行时与会话）

```bash
dsh plugin --profile web add ./dsh-leaderteam-2.2.0.tgz
dsh --profile web
```

- **DSH 原生前端**：`http://127.0.0.1:3080/`（侧栏 `LeaderTeam` 面板内提供 **「切换至 LT 原生工作台 ↗」** 按钮）。
- **LT 原生工作台**：`http://127.0.0.1:3080/lt/`（顶栏提供 **「切换至 DSH 原生前端 ↗」** 按钮）。
- 两者复用同一进程、同一鉴权 Cookie、同一工作区与运行中的团队会话，来回切换不会中断任何子智能体或治理会议。

### 独立伴侣模式启动

```bash
npx lt-ui --port 4320
```

## 2. Magpie 网关统一管理 (`lt-magpie` 或前端「网关与供应商」页)

```bash
# 查看网关状态、健康检查与版本兼容性
npx lt-magpie status

# 导入本机已验证 Magpie 二进制并启动隔离托管实例（自动沙箱隔离 XDG_* 与 DSH_HOME）
npx lt-magpie install --binary /opt/magpie/current/magpie
npx lt-magpie start --dynamic-ports

# 校验上游更新后的接口兼容性或一键回退上一版本
npx lt-magpie check-compat
npx lt-magpie rollback

# 一键将 Magpie 模型同步进入 LT 模型池与执行池（自动处理 off -> "none" 档位映射）
npx lt-magpie sync-to-lt
```

## 3. 主题与外观配置

统一采用 `--lt-*` 设计变量系统：
- **白色主题（默认）**：清爽日光工程工作台（`#FFFFFF` / `#F7F8FA`）。
- **黑色主题**：分层深碳石板（`#0F1115` / `#1A1E26`）。
- **河洛序主题**：宣纸底色（`#F5F3EE`）、焦铜轴线（`#9C5B2E`）、衬线标题与胶囊主按钮。
- **用户自定义主题**：8 项核心种子变量实时预览、WCAG 对比度校验与服务端持久化。

## 4. 衡账整合与独立运行

- 在 LT 原生工作台「衡账分析」页可直接查看多会话总览、峰谷对称成本、四桶缓存节省、真实供应商/任务归因，也可随时开启/暂停采集或纯浏览器离线拖入 `.zstd` 文件解码。
- 衡账工程（`lt-usage-plugin`）同时完整保留独立命令行与独立服务能力（`npm run scan` / `npm run report` / `npm run serve`）。
