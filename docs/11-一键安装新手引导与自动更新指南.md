# 一键图形化安装、首次使用新手引导与控制台自动升级指南

本文档面向希望**零命令行快速上手**的普通用户与需要了解底层安全保障的开发者，详细说明 LeaderTeam 的一键图形化安装器、三步新手配置向导、跨平台独立 Release 标签防串台机制，以及双发行分支隔离的自动检查更新与无损回滚体系。

---

## 一、图形化一键安装器（零命令行，自动识别默认及自定义 DSH 目录）

无需手动查找 DSH 安装目录或记忆 `dsh plugin` 命令：

1. **双击直接启动图形向导**：
   - **Windows**：解压发布包或克隆目录后，直接双击运行 **`Install-LeaderTeam.cmd`**（优先使用源码仓 `bin/lt-installer.mjs` 或独立单文件 `installer/lt-installer-standalone.mjs`；即使电脑未单独安装 Node.js，也会自动扫描默认目录、`D:\Apps\DeepSeek-Harness` 等全盘自定义目录与 Windows 注册表 `Uninstall` 项，复用官方 `DeepSeek Harness.exe` 内置运行时启动浏览器向导）。
   - **Linux / WSL2**：运行 **`./install-leaderteam.sh`**（或 `node bin/lt-installer.mjs --gui`）。
2. **向导自动完成的五项保障**：
   - **全路径环境探测与兼容检查**：自动扫描官方桌面客户端（支持默认目录、`DSH_DESKTOP_DIR` / `LT_DSH_APP`、`C:`..`Z:` 常见目录与注册表卸载项，页面同时提供显式手动路径输入框与「重新扫描」按钮）及 Web/CLI 环境，实时核对宿主兼容性矩阵。
   - **零状态桌面 Profile 自动初始化与补丁净化**：在从未启动过的全新 `$DSH_HOME` 上安装桌面端插件前，自动幂等初始化 `profiles/desktop/package.json` 与 `cordis.patch.yml`；安装后自动备份清理旧版 V2.1 遗留补丁与失效的 `leaderteam-*` 手工插入项，完整保留模型配置并自动启用联网工具 `tool-web`。
   - **运行态文件锁预检与友好中文排错**：若检测到 `DeepSeek Harness.exe` 正在运行占用 `desktop` Profile，安装前提前给出中文退出指引（命令行亦支持 `--dsh-dir <目录> --profile web` 在桌面端运行期间零冲突安装至独立 `web` Profile）。
   - **选择安装来源与可选预配 API Key**：支持随附 `.tgz` 离线包、本地文件上传/路径填写，或按当前操作系统自动匹配下载官方 Release 包（强制核验 `SHA-256`）；粘贴 API Key 后自动写入 `<DSH_HOME>/.credentials.yaml`（`version: 1`）与 `.env` 并同步 DSH 模型列表。
   - **一键直启客户端**：安装完成后点击 **“立即启动客户端”**，即可直接打开 `DeepSeek Harness` 桌面端（原生支持 `dsh-app://app/` 窗口内无缝进入 `/lt/`）或浏览器 `/lt/` 控制台。

## 二、首次使用三步新手引导（Onboarding Wizard）

首次打开 `/lt/` 原生工作台（或随时点击底部状态栏 **「新手引导」** / 按 `Ctrl+K` 搜索 `新手引导`），系统将提供交互式三步向导：

1. **第 1 步 · 免命令行接入模型 Key**：点选 DeepSeek、阿里云百炼（Qwen）、智谱（GLM）或 OpenAI（支持自定义 OpenAI 兼容网关 `/v1` 地址），粘贴 API Key 并可一键测试 `/v1/models` 连通性，自动采纳远端真实可用模型 ID、写入本地凭据库并同步至 DSH 模型选择器（杜绝模型不可见或 `session/model-unavailable`）。
2. **第 2 步 · 选择团队协作规格**：一键选择 **「标准自治团队（推荐）」**、**「轻量敏捷团队（2 成员）」** 或 **「高并发深审团队」**，自动写入全 7 角色路由与执行池。
3. **第 3 步 · 创建并发送第一个任务**：点选内置开箱任务模板（如项目结构导览、代码健康巡检），一键自动创建 `leaderteam` 预设会话并开始执行。

## 三、控制台自动检查更新、跨平台标签隔离与一键回滚

在 `/lt/` 工作台 **「设置 → 版本更新与兼容」**（或 DSH 侧边栏 **「LeaderTeam → 版本更新与新手引导」** 及 `lt-update` CLI）中内置完整桌面级升级体验：

- **跨平台独立 Release 标签自动识别（防串台保护）**：
  - 开源仓库采用 **`windows-vX.Y.Z`**（如 `windows-v2.2.2`）与 **`linux-vX.Y.Z`**（如 `linux-v2.2.2`）区分双平台异步发版（同时兼容历史无前缀 `vX.Y.Z`），详见《[跨平台独立发行与长期工程规范](13-跨平台独立发行与长期工程规范.md)》；
  - 更新器与安装器**绝不盲取 `/releases/latest`**，而是从 `/releases` 列表按当前操作系统精确过滤（Windows 仅匹配 `windows-v*`，即使远端先行发布了更高版本的 `linux-v*` 也绝不误拉；显式传入跨平台标签会立即报 `PLATFORM_RELEASE_TAG_MISMATCH` 拒绝执行）。
- **一键下载、SHA-256 校验与无感升级**：
  - 自动核对 `SHA256SUMS.txt` 或资产摘要，并在改动任何文件前校验候选包与当前 DSH 宿主版本的兼容性；
  - 在 `dsh web`（HMR 模式）下点击升级后自动热替换生效；在官方桌面端或独立 `lt-update` 下自动复用桌面端内嵌 CLI 完成替换并提示重启生效。
- **100% 保留配置与历史数据 + 失败自动回滚**：
  - 用户模型配置（`leaderteam.local.json`）、本地凭据、历史会话（`<DSH_HOME>/sessions`）与团队账本（`<DSH_HOME>/leaderteam/teams`）升级全程原样保留；
  - 升级前自动在 `<DSH_HOME>/leaderteam/updater/backups/` 生成完整离线备份快照，安装异常**自动回滚至原版本**，也可随时手动点击 **「一键回滚」**。
- **开源版与闭源免费版严格隔离检查**：
  - **开源维护版**（`Apache-2.0`）仅默认检查 [`youzi-ovo-create/dsh-leaderteam`](https://github.com/youzi-ovo-create/dsh-leaderteam)；**闭源免费公开发行版**仅默认检查 [`youzi-ovo-create/dsh-leaderteam-releases`](https://github.com/youzi-ovo-create/dsh-leaderteam-releases)；未经显式确认令牌（`409 TRACK_SWITCH_CONFIRMATION_REQUIRED`）严禁跨分支切换。

## 四、零配置自动继承 DSH 模型、空闲即时生效与会话级独立配置

1. **零配置自动继承 DSH 已配模型（以及「✨ 一键按已有模型自动配齐角色」）**：
   - 若您已在 DeepSeek Harness 宿主设置中配置好任意模型，首次启动 LeaderTeam 时会自动识别并生成本机角色覆盖（`leaderteam.local.json`），也可随时在模型与角色页点击一键自动配齐角色。
2. **手动切换模型与推理档位自动跟随（默认 `leaderModelPolicy: "follow"`）**：
   - 在 DSH 原生聊天框手动切换当前会话的模型或推理档位时，LeaderTeam 会**仅在当前会话自动同步跟随**，不再弹出“模型不一致”拦截报错；如需严格锁定仍可切换为 `enforce` 或 `warn`。
3. **会话级独立隔离 + 空闲立即生效 / 执行中安全边界切换**：
   - 点击工作台顶栏 **「本会话模型配置」** 修改模型或策略时，默认**仅作用于当前会话**（保存在 `<DSH_HOME>/leaderteam/session-configs/`），绝不污染全局默认配置或其他会话；空闲会话立即生效，执行中会话自动暂存并在回合安全边界平滑切换。
4. **严格的 User / Agent 权限分离**：
   - 仅允许用户主动操作修改全局或会话配置；Agent 执行体及 Shell 命令被权限校验（`403 AGENT_CONFIG_MUTATION_FORBIDDEN`）与安全门硬规则（`protected-lt-config`）双重物理拦截。
